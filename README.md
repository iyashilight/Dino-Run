# 恐龙快跑 · Dino Run

> **中文** | [English](README.en.md)

一个纯前端的像素风恐龙跑酷小游戏，灵感来自 Chrome 离线小恐龙。

**单个 HTML 文件**即可运行，零依赖、零构建，可直接部署到 GitHub Pages。

🎮 **在线游玩**：<https://iyashilight.github.io/Dino-Run/>

---

## 玩法特色

- **两种模式**
  - 闯关模式（runner）：经典跑酷，躲避仙人掌与飞鸟
  - 探索模式（explore）：横向探索场景，可左右移动并与会射击的敌人对战，各自独立记录最高分
- **三档难度**：普通（3 命）、中等（2 命）、困难（1 命），基础速度、障碍间距与敌人强度各不相同
- **无敌模式**：开启后免疫碰撞，可自由飞行，适合练习
- **速度调节**：滑块调节整体速度倍率（x0.5 ~ x2.0），实时按键也能临时调速
- **像素风 HUD**：生命值、分数、最高分（HI）、实时速度
- **本地最高分**：按模式分别存入 `localStorage`
- **键盘 + 触屏**：移动端自动显示左右移动与射击按钮

## 操作说明

| 操作 | 作用 |
| --- | --- |
| `空格` / `↑` / `W` | 跳跃（支持二段跳；无敌模式下按住可持续上升） |
| `←` `→` / `A` `D` | 探索模式左右移动 |
| `J` / `F` / 点击「射击」 | 探索模式射击 |
| `Shift` / `Ctrl` | 临时加速 / 减速 |
| `CapsLock` | 快速下落 |
| `P` | 暂停 / 继续 |
| 游戏结束后 `空格` / 点击画面 | 重新开始 |

## 本地运行

不需要任何依赖，直接双击 `index.html` 就能玩；也可以起一个静态服务器：

```bash
git clone git@github.com:iyashilight/Dino-Run.git
cd Dino-Run
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 技术说明

- 原生 **HTML5 Canvas 2D + JavaScript + CSS**，无任何第三方依赖
- `requestAnimationFrame` 主循环，按帧时间步进，保证不同刷新率下手感一致
- 二段跳 + 跳跃缓冲（jump buffer）+ 土狼时间（coyote time）
- 跳跃力度随速度比例缩放，速度倍率变化时跳跃弧线仍保持一致
- 程序化生成障碍与敌人，难度随进度提升
- 响应式画布，兼容桌面与移动端触屏
