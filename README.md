# 恐龙快跑 · Dino Run

一个纯前端的像素风恐龙跑酷小游戏，灵感来自 Chrome 离线小恐龙。单个 HTML 文件即可运行，无需构建与依赖，适合直接游玩或部署到 GitHub Pages。

## 在线游玩

启用 GitHub Pages 后，可通过仓库的 Pages 地址直接访问（入口文件：`index.html`）。

## 功能特性

- **三档难度**：普通（3 命）、中等（2 命）、困难（1 命），不同的基础速度与障碍间距
- **无敌模式**：开启后可自由飞行并免疫碰撞，适合练习或娱乐
- **速度调节**：滑块调节整体速度倍率（x0.5 ~ x2.0）
- **实时按键调速**：按住 `Shift` 加速、`Ctrl` 减速、`CapsLock` 快速下落
- **多种障碍**：仙人掌组合与飞鸟
- **像素风 HUD**：心形生命值 / 无敌标识、当前分数、最高分（HI）、实时速度
- **本地最高分**：使用 `localStorage` 记录最高分
- **自适应画布**：支持键盘与触屏/点击操作

## 操作说明

| 操作 | 作用 |
| --- | --- |
| `空格` / `↑` / `W` / 点击画面 | 跳跃（无敌模式下按住可持续上升/飞行） |
| `Shift` | 临时加速 |
| `Ctrl` | 临时减速 |
| `CapsLock` | 快速下落 |
| 游戏结束后 `空格` / 点击 | 重新开始 |

```bash
# 直接双击 index.html，或使用任意静态服务器
```

## 技术说明

- 原生 **HTML5 Canvas + JavaScript + CSS**，无第三方依赖
- 基于 `requestAnimationFrame` 的主循环与帧时间步进
- 跳跃力度随速度比例缩放，保持不同速度下的手感一致性
